## 🌐 Sobre o Site

Site institucional completo da **Duplas DMP Investment**, empresa angolana de telecomunicações e tecnologia, com sede em Luanda.

### Páginas Disponíveis

| Página | Descrição |
|--------|-----------|
| 🏠 Início | Homepage com hero banner, produtos em destaque e serviços |
| 📡 Internet | Planos residenciais e empresariais (8.500 Kz a 95.000 Kz/mês) |
| 📞 Telecomunicações | Centrais PABX, VoIP, SIP, Microondas |
| 🖥️ Tecnologia | CCTV, Servidores, Redes, Controlo de Acesso |
| 🛒 Loja Online | Catálogo de equipamentos com carrinho de compras |
| 👥 Sobre Nós | História, Missão, Visão e Valores |
| ✉️ Contactos | Formulário de contacto e informações |

## ⚙️ Tecnologias Utilizadas

- **HTML5 + CSS3** — Estrutura e estilos base
- **React 18** — Interface interativa (via CDN)
- **Tailwind CSS** — Framework de estilos
- **FontAwesome 6** — Ícones profissionais
- **Google Fonts** — Oswald + Barlow + Bebas Neue
